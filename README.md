# Bitaxe AI Auto Controller — Community Preview

Український проєкт моніторингу Bitaxe Gamma 601, створений за мотивами експериментів з автоматизацією за допомогою Python та ШІ.

**Статус: експериментальна публічна версія, не перевірена на реальному пристрої.** Поточний код тільки читає телеметрію й рекомендує профіль; він **не** змінює частоту, напругу чи живлення майнера. Це не повний оригінальний Auto Controller v2.

## Встановлення
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```
Вкажіть локальну адресу Bitaxe у файлі `.env`. Для macOS/Linux:
```bash
set -a; source .env; set +a
python3 bitaxe_controller.py
```

## Функції
- Читання телеметрії через AxeOS `/api/system/info`.
- Контроль температури з рекомендаціями профілів Emergency, Cool, Eco, Normal, Turbo.
- Журнал у консолі; опитування кожні 300 секунд за замовчуванням.
- Безпечний режим DRY RUN: жодних записів у пристрій.

**Увага:** пороги температури є прикладами, а не сертифікованими обмеженнями для конкретної прошивки. Не застосовуйте рекомендовані частоти й напруги без перевірки документації, охолодження та живлення. Відсутня реалізація керування розумною розеткою та погодного API. ШІ використовувався під час розробки, але цей контролер працює за правилами, а не через модель ШІ.

## Конфіденційність
Файли `.env` та `*.log` виключено через `.gitignore`. Не публікуйте IP-адреси, місцеперебування, ключі API або журнали роботи. Якщо ключ уже був у вихідному файлі, відкличте та перевипустіть його.

## Підтримка
Перевірте сумісність полів відповіді API з вашою версією AxeOS. Поки немає гарантій працездатності на всіх прошивках.
